## 文档使用规则

- 以Owner最新明确决定为准；“助手建议”“待确认”“有条件首发”不等于批准范围。
- 区分已有操作记录、页面截图、卖家声明、用户留言、助手设计与未知；策略阈值不是验证结果。
- 竞品丰富程度、源码文件数、买家关注数不能直接换算需求、策略有效性或收入。
- 当前不讨论合规，不把复杂研究Gate、统一平台或等完长期调查作为立项前提。
- 不修改其他项目或原始资料；产品编码、策略运行、部署、购买及外部发消息均需各自明确授权。
