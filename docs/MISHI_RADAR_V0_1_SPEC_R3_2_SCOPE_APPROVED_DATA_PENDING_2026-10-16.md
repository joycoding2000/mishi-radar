八策略的计算得分和排名**只在各自规则内具有含义**，不能直接跨规则相加。动量/反转/价值/质量/低波/流动六维是解释指标体系，不是八策略的替代品。资金与板块不冒充六维中的另一个“价值”分。

三种风格必须保存**可理解的配置差异**；哪项筛选资格、规则阈值或排序偏好发生变化必须显示出来并版本化；如果仅改变显示偏好，明确声明不影响候选资格。**具体风格参数/默认指标阈值尚未批准，须在正式实施合同冻结前完成明确、可测试的数值定义**。初次使用默认 S01，不要求选择风格；存在已登录用户的主动策略选择则可以恢复。

## 3. 每套策略的最低交付矩阵（Owner 批准的统一承诺）

`必` = 可用且有真实可审查的结果；`观` = 交易时段能看有时间标记的上一确认信号与当期行情，**不要求八套都每分钟全池重算**。出现数据问题时该功能暂为 BLOCKED，不能自动算作 PASS。

| 策略 | 当前全市场日终筛选 | 盘中有用观察 | 单股历史规则检验 | 历史 Top N 现金组合回测 | 特别证据 |
|---|---|---|---|---|---|
| S01 | **必** | **观**（行情/趋势） | **必** | **必** | DR01/02，全池及基准 |
| S02 | **必** | **观**（平台、实时价）；盘中放量确认须真实累计量 | **必** | **必** | DR02 成交量与实际业务日期 |
| S03 | **必** | **观**（回调和确认分开） | **必** | **必** | DR01/02 |
| S04 | **必** | **观**（昨跌与当期修复分开） | **必** | **必** | DR01/02 |
| S05 | **必** | **观**（最近确认低波、当期行情） | **必** | **必** | DR02 同单位成交额、无损数值 |
| **S06** | **必**（完整行业成员） | **观**（已确认行业广度，不伪造盘中全行业） | **必** | **必** | DR01/03/06 |
| **S07** | **必**（可知财务/估值及行业内全池） | **观**（最新公告数据与当前行情，不称实时财报） | **必** | **必** | DR03/05/06，避免回填未来财报 |
| **S08** | **必**（完整近五交易日同源净额） | **观**（上一确认日度资金与独立当前行情） | **必** | **必** | DR02/04/06，近5日缺一不可悄悄当0 |

**当前资格**与**历史资格**分开：

- `CURRENT_SCAN`：实际股票池分母及合格、剔除、缺失、失败数量；最新已完成交易日/源时点、数据单位/定义、采集吞吐；股票全池可靠性**尚未证实**，S06 当前行业成员、S07 全池财务估值、S08 最近五日资金是重点阻断候选。
- `HISTORICAL_REPLAY`：对应历史日真正已知的证券资格、行业、财务、资金与价量；复权分析与未复权成交价分离，交易日历/涨跌停/停牌、费用、未成交可对账；禁止后见之明。
- **历史目标**：向供应方请求近约一个交易年度真实复现（另加规则预热）；三年/自定义保留为后续数据范围目标。短于目标或某策略无法复现，必须 Owner 另行批准商品承诺/供应计划/发布时间变更；不能默认“有几个月数据就标称完整回测”。

## 4. 关键用户路径与历史语义

1. **首页**：今日机会，首次 S01；可恢复上次主动选择策略；其它策略一键切换，候选卡上首先呈现**入选依据、主要不利因素、数据日期/暂态、失效条件**。六维与多个时间戳可展开，不把专业面板强迫展示在第一屏。
2. **多策略同股**：合并股票条目，保留各自资格、信号、排名和版本；可对照六维与不同结论。不同窗口/任务导致分数不同不一定是错误，但必须显示原因。
3. **排名历史**：日终按默认内置规则（以及有正式发布合同的预设）保存**全合格池**名次，查询近60个实际记录交易日；尚不足60日即显示实际长度。区分 `入选TopN`、`符合资格但TopN外`、`符合资格但未触发策略`、`不满足基础资格`、`数据缺失/失败`。规则 V1/V2 不作直接同尺度比较；真实发布与离线重算分开。
4. **H1观察仓**：记录数量、平均成本、成本基准日期、参考价格时点、可用价格、估算市值/浮动盈亏、关联规则变化；更新/结束记录留不可变的数量、成本、参考价、时点、原因。不自动算现金分红、税费、已实现盈亏，遇重大公司行为明示局限。
5. **自选资金日报**：每个报告冻结当时自选证券列表，记录交易日、生成时刻、源日期、成功/缺失/失败/过期统计和股级数据；当日更改自选不篡改昨日；不把竞品3全市场缺项与用户自选缺项混同。
6. **手机实用性**：Android/iPhone 真实触控榜单、图表、筛选和回测明细，能完成完整主链；PWA 不作为必须安装项。

## 5. 数据消费者与供应项目的责任边界

DR01–DR06 是本轮**必须取得能力答复**的消费者请求，不等于供应方必须增加新接口或完成开发。详见同批文档 `MISHI_RADAR_TO_CHSTOCKDATA_DR01_DR06_CONSUMER_REQUEST_2026-10-16.md`。

## 6. 服务上限、时间与售卖承诺

- 数据刷新：至少每日有明确**最新有效日终批次**，更新延迟时显示对应日期及延迟；盘中展示有源时间/获取时间的行情与最近确认信号；真实端到端测试后确定具体发布时间、数据过期阈值和可宣传频率，不许未经实测承诺固定3秒。
- 采集与回测：后台共享采集/受控任务，不逐用户全池抓取。回测状态区分排队/运行/成功/失败/不可计算；保存配置和结果可见、可删除、带版本和输入边界。
- **暂行保护提案，非 Owner 已批准 SLA/价格/配额**：每账户最多1个运行中的重回测、10套保存配置、20份结果、最近60个交易日历史榜、¥500/月增量基础设施和每周4小时人工售后作为内部评估点。除已批准的历史排名窗口方向外，所有数字均需运营/负载证据和 Owner 商品权益决定，不可作为确定交付能力。
- 首售业务：试用、人工开通、有效期/续期、说明、帮助和失败反馈要真实跑通。售价、试用期限、商业使用许可、最终额度/时效/支持范围须在发布前提交 Owner，而非照抄竞品卖家宣传价格。

## 7. 必须通过的贯穿验收实例（不是 Alpha Gate）

1. **同股多策略解释**：固定一只同时命中至少两策略的股票（可用有边界 fixture），检查合并呈现、各自排名/规则版本、六维基础值/数据日期、不同的正反证据；风格切换只改变明确版本化的参数/显示；不制造预测胜率。
2. **排名跨版本与缺失**：同一股票从 V1 → V2，检查日终真实批次、榜内、TopN外精确名次、资格不符、策略未触发及数据失败；不得把历史重算的名次当作当时真实发布。
3. **无法成交的组合对账**：包含一次不可买入及一次持仓不能卖出，核对现金、持仓市值、费用、买卖状态、明细、组合净值和基准；无成交不得虚增盈利。
4. **真实环境数据资格**：八策略最新市场有效日终筛选与规定区间历史检验，以实际全池覆盖、成功/失败/缺失、时间和复现证据证明，不能用72条供应离线测试或4个旧样本替代。
5. **真实 PC/手机主链**：登录/权益→机会榜→诊断→行业/日度资金→自选/H1→历史排名→单股/TopN回测→保存/导出→帮助；包含上游断连、旧缓存、报价未知和到期情况。
