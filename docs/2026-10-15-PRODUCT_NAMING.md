## 主推荐：觅势

| 使用位置 | 建议名称 |
| --- | --- |
| 产品简称 | **觅势**，读音mì shì |
| 首次对外展示全称 | **觅势 · A股机会雷达** |
| 闲鱼商品描述用名 | 觅势A股选股助手，后接已实际交付的功能说明 |
| 英文展示名 | **Mishi Radar** |
| 工程/仓库目录（Owner已确认） | **mishi-radar** |
| 一句话说明 | **发现机会，看懂依据，跟踪变化。** |

“觅”对应主动发现股票，“势”对应市场、板块与个股的变化，贴近机会发现和持续跟踪。两个字易于在软件标题、安装包和口头介绍中使用；首次配“A股机会雷达”解释用途。盘中与盘后、多个选股方法及回测都能容纳在这一名称下。

英文名主要服务工程标识与必要展示，不要求中文用户先理解量化术语。`commercial`和`mvp`属于当前工作阶段，交付品牌不随开发阶段变化。
