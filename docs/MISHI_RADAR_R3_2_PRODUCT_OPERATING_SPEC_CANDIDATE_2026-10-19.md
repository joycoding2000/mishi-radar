## 2. 统一输入、时点与数学约定

### 2.1 身份及可知性

- 证券主键 `security_id=exchange:ticker`，例如 `SH:600000`；指数另带 `instrument_type=INDEX`，禁止裸 `000001` 混淆证券/市场。
- `D` 为合格日历中最新已完成市场交易日，`D-k` 为往前第 k 个市场交易日，绝非自然日或“最近 k 条”。历史在每个 D 重建当时信息集合。
- 每值携带 `business_date / effective_from,to / available_at或UNKNOWN / observed_at / source,method,unit / quality / input_version`。源时间未知可以披露；证券状态的业务有效日未知、历史首次可知版本缺失不能仅靠披露变成可用。
- 当前日终批次在 D 完成、必需输入到齐且通过已批准的使用判据后计算。`signal_date=D`，`computed_at`、`published_at` 是另外两个时刻。没有获准的日终使用窗/修订政策时，只能形成待审结果。
- 历史研究截止为 D 收盘。仅日期级公告一律从**公告日之后首个交易日**的收盘计算可用；若有可核时刻，则 `available_at≤D收盘` 才可用。这是保守的补充候选。D 收盘后公告、盘后才可知的修订不进入 D 信号。日终价量是 D 完成后的结算输入，允许形成 D 日终信号；订单不能早于下一交易日且不得早于其输入实际可用时刻。
- 真实发布订单基准：若该批实际在 D+1 开盘以后才发布，“发布后可执行”起点为**发布后第一个市场开盘**。不得展示 D+1 已过去的开盘收益为发布后收益。历史理想日频模型另有明确可用窗假设（§7.1）。

### 2.2 价格、窗口与单位

`O,H,L,C` 为当时未复权 OHLC，单位 CNY/元；`V` 为股，`A` 为真实成交额/元，绝不以 `C×V` 替代 A。`B` 为带市场身份的基准收盘。

分析窗口使用截至 D 已生效、且该时点可知的复权因子形成同锚序列 `P_t^(D)=C_t×K(t,D)`，对应高低开同乘 K；以下简写 `P,H*,L*`。只允许窗口内一致锚和一致方法，不把今天包含未来公司行为的前复权帧直接用于过去信号。量比使用同一股本基准的 `V*_t^(D)`：送转拆并股的股数因子适配，现金分红不调整量；输入不足则相应窗口不可计算。真实成交、持仓估值和现金事件始终使用原始价/股数（§7）。

| 符号 | 精确定义（补充候选） |
|---|---|
| `MA_n(D)` | `mean(P[D-n+1:D])`，含 D 的 n 个市场日收盘 |
| `R_n(D)` | `P_D/P_(D-n)-1`，n 个日收益需要 n+1 个价格 |
| `ER_n(D)` | `R_n(D) - (B_D/B_(D-n)-1)`；简单差值，非收益比 |
| `r_t` | `P_t/P_(t-1)-1`；同一个 D 锚下计算 |
| `sigma60` | 60 个 r 的样本标准差 `sqrt(sum((r-mean(r))²)/59)`，非年化 |
| `ILLIQ60` | `mean(abs(r_t)/A_t)`，60 个市场日，A 必须逐日已知且大于0；单位 `1/元`，可显示乘 `10^8` 的刻度但排序用原值 |
| `AVG_A20` | D-19…D 的真实 A 算术均值 |
| `Q+(x;X)` | 中位秩百分位 `(count(X<x)+0.5×count(X=x))/len(X)`，高值方向；低值方向 `Q-=1-Q+` |

百分位的比较池及日期必须显示。相等原值共享百分位，**最终名次不并列**：按本策略排序键后，以 `security_id` 升序收尾，得到可复现的 1…m 精确序号。不使用显示四舍五入值决定并列。输入 Decimal 保留源精度；衍生排序键统一十进制小数12位、ROUND_HALF_EVEN 后比较；版本记录算法/数学实现。展示小数位仅影响显示。无截尾、缩尾或缺值插补；无限值、非法负量额、OHLC 矛盾是 INVALID，不当作极强信号。

数学边界：空比较池无百分位；唯一有效值的 Q 为0.5（真实单样本定义，不是缺失填50）。诊断对少于2个可比样本不画相对分，显示“可比样本不足”；策略只有一个可评分成员时仍可记录其数学键和第1名并披露分母。

真实缺日不得前填。经独立事实确认全天无交易的市场日，可以在技术价格序列延续前一有效价格、V/A记0，但必须标 `CONFIRMED_NO_TRADE` 且公司行为可正确衔接；这不是成交记录。无法证明无交易则 UNKNOWN。A=0 的 Amihud 为 `NOT_APPLICABLE_ZERO_AMOUNT`，不得除零或从60日删去该日改用59日。相应策略不进入可评分池，覆盖账保留适用性原因；不能把未知资金净额据此认证为0。

### 2.3 状态与逻辑

数值、可用性、请求和业务状态分列：`VALUE`、`CONFIRMED_ZERO`、`RAW_ZERO_SEMANTICS_UNKNOWN`、`NOT_APPLICABLE`、`MISSING`、`INVALID`、`CONFLICT`、`REQUEST_FAILED`、`STALE`、`UNKNOWN`。其中 raw zero 可数值完整但语义不可用；DR04-P `COMPLETE` 不改变这一点。

## 5. 六维诊断与三风格

### 5.1 六维的计算及展示

六维是描述性画像；所有分为相对位置 `0–100=100×Q`，不是收益概率、胜率或风险保证。仅在**完整且可核的比较池**计算相对分；个股原值可以先显示。整池不完整则相对分UNKNOWN，不把未知证券删掉后仍称全市场/全行业分位。

| 维度 | 原值/公式与窗口（候选） | 比较池和方向 | 正反解释 |
|---|---|---|---|
| 动量 | ER20、ER60；描述分 `100×score01` | 与S01同日E01，高超额高分 | 跑赢市场及窗口差异；高动量不表示便宜/可成交 |

| 价值 | PE_TTM；`100×Q-(PE_TTM)` | 与S07同口径、同业、正PE的非金融E07 | 相对便宜/昂贵；低PE不自动证明质量；非正PE/金融模板不适用明确显示 |

**已接受的正式发布原则**：U有效、资格终态守恒；本策略所有需评分的适用输入、竞争横截面及必要窗口可核；已证明的不适用逐项列明；不得存在会改变该策略完整排名的未解决未知。部分数据只能生成 `PARTIAL_PREVIEW`，不是正式发布，不写入官方真实排名历史，不产生正式新增/失效提醒。具体覆盖/零语义、连续批次及运行时窗判据仍须按OD-3和DR04-M取得证据及事前批准；上述原则不替代它们，不能按预览覆盖率过Gate。

旧正式结果可继续阅读，明确“最近有效日 D_old，目标日 D_new 未发布”和具体失败；旧获取时间保留。报价独立显示来源时间UNKNOWN/获取时间，更新报价不会更新日终信号日期。周末/休市日按日历保持最近交易日，不伪造新日终批次。

### 6.3 历史记录及回溯窗

`publication_type=ACTUAL_PUBLISHED` 是实际日终发布记录；`HISTORICAL_RECALC` 是后来重算；`CORRECTED_PUBLICATION` 为带父批ID、原因及更正发布时间的新记录，旧批不可改写。默认历史轨迹读当日首次正式发布；可切查看当时已公开的更正版，必须标注。后来的更正不能替代原始发布跟踪的决策输入。

可见窗口承接A1§4，推荐最近60个**实际记录交易日**（60为既有建议，不升级为已冻结保留期）；对每策略读取最近60个有正式发布的交易日。两条记录之间未发布的市场交易日仍显示缺口，同时报告记录日数与实际日历跨度，不能把间隔补成有排名。少于60日从首次真实采集起显示实际长度；按批保存八套默认规则全E_s序号及U终态，个人无限参数不承诺官方历史。风格仅显示所以复用默认历史，不另造算法版本。不得用后补重算凑足真实记录日数。

跨规则版本、池口径/分类或资金方法改版画断点，允许并列读，不直接算名次升降。只有同版本、同排名范围、两个实际批次都有确切状态时计算变动；候选新增/退出与pool_rank变化分开。不把数据未知、缺发布或风格切换发成“策略失效”。

发布后1/3/5/10/20日跟踪分别给发布参考价收益与发布后首个可执行开盘起算收益；后续已完成天数不足为PENDING，缺价为UNKNOWN。它们是观察收益、无费用/非现金组合，和F6现金净值分开。较早未采集日期只可另开历史重算入口；不能将真实发布历史回填60日。

### 7.2 两种单股输出与组合区别

单股页统一选择证券、S01–S08或已保存参数、区间和费用配置：

### 7.3 日事件顺序、调仓与未成交

每天按以下顺序回放；所有决策携带前一已完成收盘的信号ID和原因，不看当天收盘后再决定当天开盘买卖。

1. 应用已实施且当日生效的公司行为，登记可用股数、不可售新增股、应收/应付和当日支付；更新可卖数量/价格限制。核对订单的数据可用时刻。
2. 用当日原始开盘对可报价持仓估值；已证实停牌者按上一有效原始收盘、结合已实施公司行为机械衔接并标 `STALE_MARK_CONFIRMED_SUSPENSION`。缺价且无可核原因时当日权益UNKNOWN，任务阻断，不能以0估值。
3. 计算扣费前开盘权益 `E_open=cash+receivables-payables+Σ(q×mark_open)`；固定本轮目标单名金额 `W=E_open/N`。当日后续成交不重新放大W。
4. 先处理已锁定退出（止损/到期/策略退出/已知失去基础资格），再处理调仓移出及减到目标权重的卖单；退出按 `首次触发日,security_id`，其它卖单按security_id排序。不得同开盘为退出股重买；即使又入选也等下一次调仓。多个退出原因全部记录，主原因顺序：资格风险→止损→策略失效→到期→排名调出。
5. 卖不出继续占实际仓位和行业名额，按原始价/可核停牌估值；锁定退出每日后续开盘重试，直到成交/区间结束，不因条件恢复取消已发生的退出。UNKNOWN不是新增退出；但缺关键输入的真实回放保留已知前缀并停在BLOCKED，不能跳过该日继续报成功。
6. 调仓时用上一收盘候选全序：保留仍在目标名单的旧仓，先调减超W部分；再按候选序号处理买单/补足。S04遵守§4.4及P1“不补仓”：已有S04仓位不追加买入，不能被通用补足规则覆盖。其它规则的买入金额上限为 `max(0,W-当前持仓开盘价值)` 且含当次买入费用，实际现金不足时进一步缩小；S04首次建仓同样适用此上限。只按当时交易单位取**最大合法且连费用可负担**数量，不借钱；原有不可卖超配持仓标实际偏差，不假装已调平。
7. 买入受阻当次跳过，沿同一份上一收盘排序尝试后续合格股，至N个实际证券或候选耗尽。S06的**正式候选与执行备选队列分开**：仅当某强行业正式前2受阻，才允许按上一信号日该行业的原industry_trigger_rank顺次尝试后续股；备选必须在该信号日已通过E0、强行业及绑定S01条件，且满足当日基础/交易资格、现金及实际行业持仓限额（默认2只，个人更低限额从其配置）。不得用当日新信号/涨幅重排或从另一行业冒充同业递补。不能卖的旧仓继续占名额，达到或超过限额不新增同业股；超额保留并显著列明约束未实现。回测明细标 `EXECUTION_REPLACEMENT`，保留被替代候选/受阻原因、信号日/绑定版本、原pool_rank及行业内两种序号；正式前2之外的递补股candidate_rank仍为null、正式身份仍为CONCENTRATION_EXCLUDED，不伪造“原候选名次”或改写发布榜。
8. 非调仓日不做上述买单。新建仓当日受有效卖出限制，不因其它退出条件绕过；已持旧股能卖多少按可售批次数量。减仓后回补仍算同一持有周期，不能重置最长持有日；整仓退出后下轮重入才新开周期。机械定期目标调整不是额外的摊平加仓策略，不做非调仓日补跌。
9. 日终按原始收盘或已核停牌估值计市值，汇总现金/费用/应收应付，输出权益/净值；成交现金及费用已按§7.4即时记账，日终不重复入账或扣费。再用 D 收盘信息判断退出、生成未来订单，计持有交易日。

Owner 已批准S06“正式榜单每行业前2、受阻可用同强行业已合格后续股递补”的执行例外，未放宽正式榜单资格。个人行业限额为1时，正式槽位和实际持仓同从该限额，受阻递补不扩大名额。一般规则的次日基础资格若已知转坏则不买；该日不能凭新增财报或行业资讯重新优化上一日排序，只做执行资格否决。

订单状态：`PLANNED → FILLED / PARTIAL_QUANTITY / UNFILLED / BLOCKED_UNKNOWN / EXPIRED`。`PARTIAL_QUANTITY` 仅指资金/合法数量约束缩量；本模型不声称还原真实盘口部分成交。每单记录信号/尝试/成交时点、计划与实际数量、价格、费用、失败原因和重试关联。已知停牌/价格受限/现金不足的UNFILLED是正常模拟结果；输入未知的BLOCKED不能算正常“当日未成交”来掩盖数据不合格。

### 7.4 开盘成交、限制、费用

这是**日频假设成交模型**，不声称知道严格09:30逐笔成交、委托队列或大额订单容量。默认仅当原始O有效、有相容的当日交易事实、证券/账户模型适用资格和交易规则均已知、价格限制允许时，按O加不利滑点尝试完整模型数量。日H/L/C只用于数据校验/收盘分析，不能用后来开板/最高最低价格决定早先开盘成交。

- 买入开盘价达到/超过有效涨停价则本次不买；卖出开盘价达到/低于有效跌停价则本次不卖。即便日内后来开板也不倒填开盘成交。仅一个方向受限不擅自阻止相反方向。
- 买价 `ceil_to_tick(O×1.0005)`，卖价 `floor_to_tick(O×0.9995)`；若滑点后价越过有效价格限制则 `PRICE_OUTSIDE_LIMIT` 不成交，不夹到涨跌停价后假装成交。合法无价格限制的日子须有明确规则记录，UNKNOWN不能当“无限制”。
- 全天停牌/零交易事实冲突、缺开盘/停复牌有效日、限制值或板块制度未知分别给原因。不能从日线存在、`tradable=True`或[09:30,09:31)活动代理推导任意订单可成交。
- `TradingRule(date,exchange,board,security_type)` 至少包含生效起止、来源/版本、价格档位、买入最小数量/数量步长、零股全量卖出规则、可售延迟、涨跌幅或当日限制价及无价格限制标记、上市特殊期/风险警示适用性、卖出资金当日可用规则。真实运行前以DR06事实及权威规则核定；**不在本文将“所有股票100股/一律10%/一律T+1”当合同**。
- `FeeSchedule` 分开佣金、交易税、过户/其它必要费用、股息税；键含生效日/市场/证券/方向及必要持有批次。`gross=q×fill_price`，`commission=max(gross×0.0003,5)`（成交才有）；其它费用 `gross×适用费率` 或相应明确计费基数。每个费用分项按表规定取整；无规定的模型金额统一ROUND_HALF_UP到分。不能把未知税费默认为0；“不适用=0”必须有明确规则依据。
- 费用日分录：买入现金减少gross+买费；卖出现金增加gross-卖费；滑点已经进入成交价，不再重复扣费。旧批次后续卖出、送转产生零股和股息税按批次追踪；这些是F6模拟内部明细，不升级H1为用户交易账本。

本轮没有核验现行交易制度或法定税率，不发出投资/税费建议。费用和交易规则表是必需的可版本化执行输入，其缺口属于DR06/模型冻结前证据，不能由Owner一句“接受模型”替代事实。佣金/滑点是假设候选，可在报告中修改并存版本；基准、税费、单位、模型不同的结果必须突出差异。

### 7.5 公司行为、现金及退市

分析复权与资产账分离，不能用复权价买卖，再额外发一次分红。只有已实施记录进入账；预案、取消、仅公告不产生现金/股数。

- 现金分红：登记日冻结实际有权数量；**除息生效日**才按该数量确认应收，避免登记日价格尚含息时重复计权益。支付日由应收转现金，不再增加总权益；除息后卖出也不取消已取得的分红权。股息税按已核版本计应付/实际扣付，涉及持有期的不确定性必须有明确计提规则；缺失则相关真实回放阻断，不能随意免税。
- 送股/转增/拆并股：按已证实的有效权益归属及比例调整股数，原头寸总成本不变、在变更后股数间重分摊，每股成本及固定价格阈值同比例调整；新增股上市可售日期前不可卖，但已生效股份计入未平仓股数和估值。清仓后才交付、仍属原有权批次的股份/现金权利留在原周期，不能赠给新周期。小数股份/现金替代依合同事实，不擅自舍掉。现金分红不冲减交易成本，依下述归属分别计入已实现部分与未平仓部分，合计进入周期总损益。
- **剩余成本与已发生费用**：每证券/持有周期按加权平均分配成本。`C_open`为剩余未平仓成本，买入时增加实际gross及已发生买费；补买增加股数和成本但不重置周期。部分卖出q_sell、售前股数q_before时，转出成本`C_sold=ROUND_HALF_UP(C_before×q_sell/q_before,2)`，`C_open=C_before-C_sold`；全卖转出全部尾差。卖出实际gross减已发生卖费再减C_sold计入已实现交易损益，卖费只归售出部分；净卖出回款进入现金，不冲减C_open。滑点已在gross内，不二次收费；未成交不收费，不预扣未来卖出费用。
- **分红权益归属**：登记日按实际有权批次冻结，除息生效日才确认。`D_open`为仍归剩余未平仓股份的累计净分红权益，包含已收及应收、减去对应已计应付股息税；各笔权益须保留有权股数和原周期。部分卖出时，按售出对应有权股数占该权益尚归未平仓股数的比例，将相应既有分红权益转归已实现部分（ROUND_HALF_UP分配到分、尾差留剩余，全售结清）；以后支付/补计税仍归原部分。新增买入股不得取得此前登记的权益，已售部分权益不得加进D_open。支付只将应收转现金，D_open同一权益不再加一次；已收股利即使现金被用于其它买单也不重复记收益。
- **8%止损**：仅在剩余股数>0、C_open>0且归属/估值完整可核时，收盘计算`R_open=(剩余原始价市值+D_open-C_open)/C_open`；默认`R_open≤-0.08`触发共同止损，关闭/其它阈值从原白名单。已实现交易损益、已售部分的分红及全部卖出回款均不得参与该判断。送转只机械衔接股数/成本；正常现金除息的市值减少由同一权益的D_open衔接，不因除息机械触发。未知成本/费用/权益或估值使风险UNKNOWN并按§7.3阻断相关真实回放，不冒充未触发；已知其它退出仍独立记录。触发收盘后按§7.3/4在下一可执行开盘尝试，失败继续占仓和重试；不是按阈值保证成交或保证亏损上限。界面短文“按剩余未平仓头寸经济亏损触发”。
- 历史已知ST/退市整理等资格变化产生退出而非删除历史持仓；若不可卖继续占仓。终止上市不得自动按0或最后价假装清算；有合格实际现金结算/后续可核价格按事件处理，否则标终止后的权益UNKNOWN并阻断完整绩效。
- 配股等需追加出资事件：候选模型默认不参与主动认购；仍须有不参与时的权利/价格/补偿处理事实。合并换股等超出既有已核事件处理能力时保存截止前缀、BLOCKED_CORPORATE_ACTION，不能排除这只历史证券来美化回测。按目标全池全区间需完善相应规则或Owner明确裁决，不将此例外算全交付PASS。

### 7.6 净值、基准与指标

每日收盘 `Equity_D=Cash_D+Receivable_D-Payable_D+Σ(q_i,D×MarkClose_i,D)`，`NAV_D=Equity_D/C0`。MarkClose为有效原始收盘价；已证实停牌且无当日收盘价时，沿用§7.3的上一有效原始价及已实施公司行为衔接，并保留停牌估值标记。既无有效价也无可核停牌估值时Equity/NAV为UNKNOWN并阻断，不能直接略去该持仓。s开盘初始NAV=1，s日收益包含当日成本。`ret_D=NAV_D/NAV_prev-1`，首日prev=1；基准同在s开盘重定为1，`Benchmark_D=B_close(D)/B_open(s)`，按同一交易日历取收盘序列。基准首日开盘未知时不能改用前收盘，真实对比阻断。基准无交易费用/不含红利，组合资产账计实际分红，必须显示这项口径差异；这是模型基准候选，不是另一个模拟成交账户。

| 指标 | 精确定义与边界 |
|---|---|
| 累计收益 | `NAV_e-1`，含未平仓、应收应付；不是已实现利润 |
| 年化 | `NAV_e^(252/T)-1`，T为实际已完成净值日数；NAV≤0不适用；不足一年标“短区间年化” |
| 累计超额 | `(NAV_e-1)-(Benchmark_e-1)`，简单差值；不用未定义比率 |
| 回撤/最大回撤 | `NAV_D/max(1,NAV_s…NAV_D)-1`，最大回撤为其最小值的绝对值；初始1参与高水位 |
| 夏普 | `sqrt(252)×mean(ret)/sample_std(ret)`，无风险利率假设0；少于2期或标准差0为N/A |
| 胜率/盈亏比 | 已完整结束的持有周期净损益>0的个数/结束周期数；平手计入分母单列；盈亏比=盈利周期平均净利润/亏损周期平均亏损绝对值，无亏损或无盈利为N/A |
| 交易数 | 成交买单数/成交卖单数、结束周期数分列；失败尝试不计成交笔数 |
| 换手/仓位 | 日单边换手=`(买入gross+卖出gross)/(2×前日收盘权益)`，首日前权益C0；仓位=`持仓市值/Equity`，应收单列；分母≤0为N/A |
| 月/年/固定分段 | 连续净值在边界相除，首段从1开始；不重置持仓/现金；未完成月年标注。固定规则分段不是训练WF/样本外证明 |

每个结束周期的净损益来自其全部买卖、费用及公司行为分录；持仓归零且全部归属分录金额/权利义务可核后计算，**不要求净现金流等于0**（盈利周期净现金流本就可为正）。清仓时按§7.5同一资产账，周期净损益=累计净卖出回款+净已收分红+分红应收-尚未支付的相关应付-累计买入支出；已确认但尚未支付的应收/应付仍计原周期损益及组合权益，不转入新持有周期，支付时只是现金与应收/应付互转，不再增加一次损益。尚有未知分录的周期不得伪报完整净损益；未平仓单列。另按§7.5分别记录“已实现交易损益+归已售部分净分红权益”及“未平仓经济损益=剩余市值+D_open-C_open”，并单列未平仓收益率R_open；两部分损益相加等于周期总损益，归属分红只出现一次。周期总收益可为正而R_open已达止损，禁止以总收益覆盖未平仓风险。现金、应收、应付仍只按Equity公式各记一次，D_open是风险归属记录，不是额外资产分录；H1不升级为该模拟账本。展示策略与基准曲线、回撤、每日持仓/现金/应收应付、费用分项、交易/失败、输入缺口。无信号且数据完整：成功、现金NAV=1、交易指标N/A；缺输入：BLOCKED；系统计算失败：FAILED；不能把三者合并为空曲线。

保存完整参数/信号时点/算法/输入hash/区间/成本/限制/公司行为/基准版本与结果。首版两份保存结果并排对比；不同时段、池、资金、规则、成本或输入版本显著列差异，可查看而不宣称可直接横比。导出摘要/参数/成交及失败CSV，日期ISO格式、金额/股数带单位、状态保留，CSV防公式解释；不是用户必须先下载才看懂。

### 8.2 H1 静态观察仓

输入：security_id、当前数量q>0（有限数值）、平均成本c>0（元/股）、成本基准日期（不得在未来）、关联规则/配置可选、备注可选。手工持仓数量可以包含零股，不套用回测买入最小单位；数量不伪称券商可售数量。状态：`ACTIVE → CORRECTED（新版本仍ACTIVE） → ENDED`，结束后只读；再次观察创建新记录，保留旧快照。

参考价P为最新可用**原始价**（盘中与日终标清），静态市值=`q×P`，参考成本=`q×c`，静态浮盈=`q×(P-c)`，浮盈率=`P/c-1`。没有新价时可显示最后参考价及日期/过期标志，当前浮盈标“基于旧价”；无价则市值/浮盈UNKNOWN，不用复权价配未复权成本。持有交易日按基准日至当前业务日的合格日历计数，基准日非交易日从之后首个交易日起算。

这不是成交账本/账户收益：不核已实现盈亏、佣金税费、分红送转自动成本或净值。重大公司行为或用户更正后显示“数量/成本需本人核对”；未核对时浮盈加“不具公司行为调整”标记。关联规则退出提示基于已确认日终输入；UNKNOWN为“暂不可判断”，绝不自动结束记录。结束由用户主动操作，保存当时数量、成本、基准日期、参考价/日期或UNKNOWN、规则状态、原因、结束时间；更新也保留旧版，不将手工更正伪装为成交。

### 8.4 任务、权限与设备状态

回测任务 `DRAFT → VALIDATING → BLOCKED_DATA 或 QUEUED → RUNNING → SUCCEEDED / FAILED / CANCELLED`。重复提交使用请求幂等键，任务展示ID、当前阶段和已处理/总量（可核时才显示百分比），禁止编造剩余秒数。用户离页/断网不取消服务器任务；返回读取原任务。失败保存失败输入和可核前缀，不能拿旧成功曲线装新结果；重试生成关联任务。保存结果只接受成功完整结果，阻断前缀可下载诊断但不列“已完成回测”。删除用户保存结果需明确操作，不能删除共享发布历史；不必新增通用任务平台。

权益候选状态 `NO_GRANT / TRIAL_ACTIVE / PAID_ACTIVE / EXPIRED / DISABLED`；试用/付费由服务端授予，不信客户端日期。有效期按Asia/Shanghai展示、按明确时间戳判断：`now<expires_at`有效，到点进入EXPIRED；人工续期从max(now,原expires_at)顺延，记录操作者/原新值。售价/期限/额度尚待OD-3，不能默认180天/29元。到期候选政策：已保存结果、自选/H1/帮助只读保留；停止新的受限计算和编辑；已有运行任务完成后保留结果，只读访问，避免到期丢任务。正常权限不足与数据失败显示不同原因，服务端校验每次操作。

PC可用表格/并列诊断；手机采用卡片/分项展开、图表纵向排列、明细可单独横滑，关键状态/操作固定可达。布局不依赖不受控内容长度，禁止整页宽表把按钮挤出屏；输入错误贴近字段且保留已填参数。返回榜单保留策略/筛选/滚动位置，跨页面携带实际规则/批次ID，不恢复成另一天默认条件。

可选PWA只提供同一Web的入口便捷性；不要求安装，不引入离线计算或推送承诺。若实现静态资源缓存，升级版本可提示重载；离线时仅显示已保存且带原日期的页面/结果，“离线，数据未更新”常驻，禁提交写操作，不排队伪装已保存。登录失效重新登录后重试需幂等；不得把跨账户的自选/结果混入缓存。具体前端框架/数据库/队列技术不在本候选新增决定。
