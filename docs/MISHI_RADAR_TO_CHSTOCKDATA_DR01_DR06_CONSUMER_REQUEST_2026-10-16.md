### DR03 时间语义修订（Owner 批准，2026-10-23）

`actual_classification_effective_date` 是行业分类客观生效日期，来源未提供时可为 UNKNOWN；`published_version_usable_from` 是根据官方公布日期确定的保守版本使用起点，二者不得混同。日期级公布在现行日终模型下从下一交易日收盘可用，执行仍遵守输入可用后的开盘规则，不重复推迟已归一化可用日期。不要求逐日迁移档案、逐秒 known_at 或逐股每日生效证明，不因半年度发布频率本身拒绝来源。已知历史修订风险必须披露，不能冒称字节级 PIT 已认证；无分类新股、遗漏、未分类及来源失败保留 UNKNOWN/原状态，不默认行业或非金融，不从全池分母静默删除。当前/历史全池覆盖和 S06/S07 排名正确性要求保持；不改变 DR01/05/06 及其它合同。详见 Owner 决策记录中的 DR03 时间语义修订条款。

### 应答结构与最小证据

逐个 ID 分别回答两个维度，不可合并为一个笼统 PASS：

- `CURRENT_SCAN_STATUS`、`HISTORICAL_REPLAY_STATUS`：各自 `SUPPORTED / PARTIAL / UNSUPPORTED / UNKNOWN`。
- 可调用的**公共接口、签名、发行版本**或无公开合同的准确事实；不能仅列内部 `_bridge` 私有函数就称支持。
- 覆盖市场、当前股票总数/有值数/缺失或失败数、源数据交易日/采集时间、字段单位与来源/计算方法、窗口、历史首尾与空洞、批次耗时/请求约束、供应稳定性边界。
- 有代码/测试即引用路径和版本；真实样本、稳定性/延迟/商业许可未知时如实 `UNKNOWN`。原有 **72条离线测试**、**4只截至2026-09-22的本地日线**不等于实时全市场能力资格。
- 最小供应方响应选项：`ALREADY_SUPPORTED` / `SUPPORTED_WITH_BOUNDS` / `NOT_AVAILABLE` / `REQUIRES_SEPARATE_PROPOSAL`；对无法满足需求，说明最小缺口及能证实的替代能力，但**不得开始实现**。

## 参考已知风险（验证对象，不预设修复）

1. `get_fund_flow()` 是人类可读文本而非无损日度数值合同；缺失有被显示为零的路径；TDX当前值与新浪日度历史口径不同，最近20条不等于任意日期历史。
2. `get_valuation_history()` 公共输出的主要是最新估值及历史分位摘要，不等于可回放的每日PE序列；财报按公告日期过滤不等于保存所有旧修订版本。
3. 当前行业背景不构成完整当日行业成员矩阵，亦无已确认历史成员有效区间。
4. 当前停牌状态接口不构成完整历史 PIT 交易资格；一个开盘活动代理也不证明全市场每笔订单可以成交。
5. `fetch_daily_bars()` 默认路由与本地 VIPDOC reader 的 Amount 合同有差异；须以实际可供消费者使用的数值接口为准。
